# Simple Blender Model

Create a simple model in Blender (more than just a primitive shape) and export it to a `.glb` file.


## Acceptance Criteria

- [x] A recognizable, simple prop made with at least one basic mesh-editing operation has been created in Blender
- [x] The model is saved in the native format (`.blend`) and exists in `assets/models`
- [x] A corresponding export (`.glb`) exists next to it, in `assets/models`
- [x] The `.glb` file has been imported into a fresh Blender scene and checked for correct shape, orientation, scale, and material
- [x] A new devlog entry has been created, with details on the model creation steps and export settings
